# TagNote Web

Веб-приложение для управления заметками с тегами, с возможностью фильтрации.

## Технологический стек

- Java 21
- Spring Boot 3.2.x
- Spring Security + JWT
- Spring Data JPA (Hibernate)
- PostgreSQL
- Liquibase
- Swagger/OpenAPI
- JUnit 5 + Mockito

## Статус проекта

В разработке

## Запуск проекта

```bash
# Клонирование репозитория
git clone https://github.com/ВАШ_НИК/tagnote-web.git

# Переход в папку проекта
cd tagnote-web

# Сборка проекта
mvn clean install

# Запуск приложения
mvn spring-boot:run
